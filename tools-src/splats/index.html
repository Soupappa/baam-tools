Mes couleurs

Les couleurs vont du haut vers le bas des mots et le long des traits. Dans un script : {perso}.

Une étape par ligne. Un mot ou une phrase courte, / pour aller à la ligne. Formes : [sphère] [tore] [galaxie] [vague] [soapy] [nuée]. Palette : {crépuscule} {baam} {feu}. Durée en secondes après |.
